# jo-pmd-site-kpi | 東淦工程 PMD 地盤同事 KPI 監察系統

本專案專為 **東淦工程 (Jumbo Orient Contracting Limited)** 的 **PMD (Project Management Department)** 設計，用於定期監察與評核地盤同事（如高級管工、地盤組員）之 KPI 績效表現。

## 🎯 PMD 特色功能
1. **多方評分機制**：整合 PMD 監察代表、直屬主管、組內同事及工頭之反饋意見。
2. **客觀數據扣分**：自動根據地盤每日報告、驗收批次、安全整改與損耗率計算得分。
3. **一票否決機制**：支援嚴重失聯、人為重大事故等條款之強制 F 級判定。
4. **標準化 PDF 匯出**：生成包含 4 方簽署欄（員工、主管、PMD 代表、HR）的官方 A4 評核報告。
